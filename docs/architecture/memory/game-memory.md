# 游戏侧记忆

> 游戏侧的记忆有三块：单个玩家与她的一对一履历（游戏玩家档案）、多人存档的群体环境（游戏社交事实）、存档隔离（同一款游戏的不同存档是互不相干的世界）。全局规则见[总览](README.md)。

## 游戏里的人

代码在 `src/modules/storage/game_player_ledger.py`（写库）、`memory/cues.py`（玩家线索）、`memory/settle_players.py`（承诺对象核对）。

- **认人与记录**：写库那一侧订阅游戏公屏与 `game.player.interacted`，只给带 UUID、核对过在线的发言人建档。记打招呼（一场一行）、送东西、切磋。游戏公屏落 `game_chat`（认不出是谁的一句只存占位、不存原话），私聊不写库。改彩排时撤掉本场互动。
- **见过他的存档**连同那台服务器验不验正版账号（`online_mode`：on / off / unknown）一起记，报了的按最新的写，没报的不抹掉已知的。记忆页"游戏里的人"列出这些存档，离线模式的标明"按名字认人，改名算新人，冒名认不出"。
- **玩家线索**：本回合在游戏公屏开口或冲她做动作、以前在正式场里和她有过往来的玩家，推一条线索（打招呼、送东西、切磋，现在与以前的名字，答应过他还没了结的事）。按 UUID 对上，同一位有限频，她本场回应过他就不再推。不进记忆摘要，只给规划器，不给游戏 Agent。六种线索见[线索推送](cues.md)。
- **对玩家的承诺**：证据二选一，都必须是她自己说出去的——她回应这位玩家的台词（写库时记下了回应对象），或她在游戏公屏打的那句（点了他现在或以前的名字；或紧跟在他上一句之后的连续对话里）。对不上不登记。
- **对号与删除**：玩家与观众不自动对号，运营者在记忆页确认关联，关联永不告诉她，只用于连带删除。删玩家时他的互动、游戏公屏、对他的承诺一起删，他的名字（含以前的名字）在她的台词、档案、承诺、游戏事件、她打的游戏公屏字里换成"一位玩家"，UUID 进不记录名单。删观众或观众"忘了我"连带删确认过关联的玩家。玩家在游戏公屏打"忘了我"和观众同一套口令与宽限期。

## 游戏社交事实

代码在 `src/agents/streamer/tools/social_fact.py`、`memory/settle_social.py` 与 `repos/social_facts.py`。

多人联机存档里"谁和谁是什么关系、什么机器大家公用、眼下服务器里谁在牵头忙什么、她平时扮演什么分工"归 `game_social_facts` 表，按 `(game, save_id)` 分账。

- **封闭类别**：`setting` 环境形态、`members` 成员关系、`sharing` 共享惯例、`works` 进行中的事、`her_role` 她的角色、`open_questions` 待弄清。每类每存档有现行条数上限，每次注入有总条数上限。
- **分工边界**：她自己亲历的事件归场次档案，她当众答应的待办归承诺表，单个玩家与她的一对一履历归玩家互动表。
- **证据门槛**：场内工具只允许游戏公屏已核实玩家原话经一字不差的校验直写现行；引用观众弹幕时要求她本场已送达回应，且只写入待审候选（见[审核与删除](review-deletion.md)）。下播整理没有原话作证的归纳行（未锁定的 `her_role` / `open_questions`）与未锁弹幕行不进每轮常驻【游戏社交事实】，仅留库供检索与审核。
- 单场跨多存档发言时，没有原话作证的归纳行归入整游戏级（`save_id=""`）。代号"玩家N"按整词边界正则还原真名。
- **陈旧降级**：未锁定的 `works` 隔过多个时长达标的已完结正式场未再证实，读时降为"待确认的旧进展"排到末尾并附注说明；满了上限时写入新 `works` 自动让位被取代。
- **删除**：删观众或删玩家时，先按证据外键整行删除拿本人话语作证的社交事实行，再把其余提及该名字的社交事实、游戏工作文档（`game_work_docs`）、场内更正与整理断点统一把名字换成代号。

## 存档隔离

同一款游戏的不同存档是互不相干的世界，关联了游戏的记忆只在说它的那个存档里成立。同一 `save_id` 在历史事件里出现过多个显示名称时，统一按 `save_id` 归并并展示最新非空存档名。

- **眼下在哪个存档**：主播每个决策回合回合开始前从 `ToolRegistry.current_saves()` 拉一次（游戏工具面的只读方法，报不出存档的游戏不在结果里）。某个游戏从一个认出的存档换到另一个时，清掉这个游戏已了结的委派与补充要求；任务清单上还在做的留着。
- **写**：下播整理按台词时刻对上这一场各游戏的存档时间段，取台词之前最近开始的那一段。这个游戏这一场没有带存档的事件就不记。
- **读**：判定集中在 `src/agents/streamer/memory/saves.py`，一条记忆相对眼下存档分四种：

| 游戏眼下 | 记忆记着存档 | 记忆没记存档 |
|---|---|---|
| 报不出存档 | 照旧（不分存档） | 照旧 |
| 还没进存档 | 别的存档 | 不确定 |
| 在存档 b 里 | s 是 b：本存档；否则别的存档 | 不确定 |

"别的存档"的事不当成眼前的事推给她：记忆线索不催她提起，摘要折成一行、回忆逐条注明在哪个存档；"不确定"的照给并注明。升级前的旧数据存档为空，按不确定照给。

## 游戏侧只读桥接

`MinecraftAgent` 通过 `social_rules.py` 在认出具体存档及新开委派任务时，异步加载当前存档已核实的公共规矩（条数以代码为准）。

- 只收已人工锁定的四类（`sharing` / `setting` / `members` / `works`）；严格拦截未人工锁定的观众弹幕作证行与无引文行。
- 作为固定层任务上下文供角色遵守共享设施与领地规矩。换存档立即清退缓存与开局消息。
- 与主播包保持零导入依赖。

这条只给游戏 Agent，不进主播的记忆摘要与回忆工具。
