# 线索推送

> 每批新弹幕进来时算一遍"这一批她该想起的事"，做成几条线索放进参考段。线索只给规划器；她若提起，编号随调用单传给回复器。全局规则见[总览](README.md)。

代码在 `src/agents/streamer/memory/cues.py`、`passive.py` 与 `render.py`。

## 线索一览

六种线索，同一种东西：一次推送。都由同一套渲染函数产出，给规划器的写法带详情，给回复器的写法只有动作标题。

**一种记忆一个出场入口**：对某位观众的承诺只在 ta 开口时出现；对某位游戏玩家的承诺只写在玩家线索上；对所有人许的承诺进记忆摘要的【还惦记的事】。

| 线索 | 装什么 | 什么时候出 |
|---|---|---|
| 承诺线索 | 对某位观众或对所有人的、还没了结的承诺（只给动作标题） | 对象开口、意思相近命中 |
| 老观众线索 | 某位老观众是谁：关系定位、曾用名、已批近况与共同造梗归属 | ta 开口且本场还没回应过 |
| 玩家线索 | 某位游戏玩家是谁、跟她有过什么往来 | ta 在游戏公屏开口或冲她做动作（详见[游戏侧记忆](game-memory.md)） |
| 往事线索 | 一条档案行的标题加原话 | 触发词、走到地点、意思相近命中 |
| 老梗线索 | 老梗栏里被提起的梗 | 本批弹幕提起老梗 |
| 遗忘回执 | "忘了我"已停记、撤回已生效的处理结果（用弹幕编号指人，不写名字、不复述说过的事） | 命中遗忘或撤回短语 |

## 优先级

每批按优先级算，推送条数有上限：

| 优先级 | 线索 | 判定 | 出哪条线索 |
|---|---|---|---|
| 1 | 对象开口 | 本批发言人名下有未了结承诺（按外部 ID 精确解析出观众编号，只读不建观众，有待删请求的不算）；或是本场还没回应过的老观众且名下有已批近况或共同造梗；或本回合在游戏公屏开口、冲她做动作的玩家以前有过往来 | 承诺线索 / 老观众线索 / 玩家线索。同时把这批弹幕的熟悉程度随调用单透传给回复器，好放轻松接话的语气 |
| 2 | 走到地点 | 角色从远处走进某个记住的地点跟前（同一存档，每个地点每场一次） | 关联那个地点的档案行或还没长期没再提的游戏承诺 |
| 3 | 触发词 | 本批观众弹幕里出现档案行的触发词或老梗栏的梗（归一化，长词再按拼音）；她最近几句台词说到触发词的，仅当该档案行不在记忆摘要且出自更早的正式场才算 | 往事线索、老梗线索 |
| 4 | 意思相近 | 配置了嵌入服务时（嵌入服务是把文字变成向量去比相似度的外部服务）：最新几条弹幕逐条、或游戏情境（存档、走到跟前的地点、手上的委派，变了才查）与档案行、还没长期没再提的对所有人许的承诺达到相似门槛且融合后排进前列。不认她自己的台词，对某位观众的承诺不走这一路 | 往事线索、承诺线索 |
| 5 | 老观众在场 | 本批开口或首次进房的观众，本批没拿到承诺线索或老观众线索、她本场还没回应过、没有待删请求（进房的老观众需来过几场以上正式场；同平台待确认身份关联簇合并去重场次数、互动计数、大航海与曾用名） | 按熟悉程度分层（常来的老熟人 / 眼熟的老观众）附曾用名与近远档位词（只有"前几天刚来过""有阵子没来"两档），人数多时写"等 N 位" |
| 6 | 遗忘回执 | 本批弹幕命中"忘了我"，或命中撤回短语且写库那一侧确认撤回已生效 | 遗忘回执 |

## 推与不推

- 游戏承诺线索**不按"游戏开着"轮播**，只在对象开口、走到地点或意思相近命中时单推。
- **用上即停**（指这条记忆既然被说出来了，本场就不再重复推）：本场台词的 `memory_refs` 里已经有这条线索的编号（`约#N` 或 `档#N`）就是被用上了，本场不再推——每批查一次库，进程重启也不丢。
- **限频**：同一条线索每场有推送上限与最小间隔（计数在内存里，进程重启后从零算）。
- **不推的情形**：记忆摘要里已经列着的、已算作长期没再提的承诺、别的存档里的、发过"忘了我"的观众触发的、模拟消息、遗忘命令本身。只由她自己台词命中的（自触发）每条每场只推一次。
- 某位观众本人有线索时，不推他自己的老观众在场行；别人的线索不压他这一行。
- "回应过"每批查一次库，她回应 ta 之后这一行立即消失。
- **留痕**：每推一条线索记一行 `memory_cue_log`（哪一路命中、分数、用上的时刻，只记条目编号，不记观众身份或玩家名字）。语义向量路每次查询的前几名余弦分数无论是否达到推送门槛都记入——推出线索时附在 `detail.top3`，未推出任何线索时记为 `card_kind="vector_probe"` 探针记录，复盘页与唠叨统计排除探针行。
