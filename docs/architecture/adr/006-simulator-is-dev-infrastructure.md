# ADR-006：LLM 模拟器是官方开发基础设施，mock 采集器仅承担确定性回放

- 状态：已采纳
- 日期：2026-08-28
- 实现提交：`ea9cde3713ebe6c0692418fd75fa4e31a397df70`（feat(simulator): ADR-006 LLM 模拟器归位开发基础设施）
- 相关审计：`.omo/audits/2026-08-27-unfinished-systems-audit.md` E2（Simulator 包）

## 背景（Context）

v1 时代模拟直播间曾是功能巅峰（LLM 驱动观众生成、人设池、四态节奏、礼物/SC 生成、WebUI 实时控制、token 预算），被提升为 `SimulatorService` 一等公民。v2 重构定案时（用户 2026-08-23 拍板），simulator 被决定"合并进 `modules/collectors/mock/`"。该拍板在**不了解实际能力差距**的情况下做出，执行层将其落实为"建简化版、弃库"：

- `collectors/mock/mock_collector.py` 自建了一套简化模拟（泊松骨架 + 5 句硬编码模板），**零复用** simulator 包代码；
- `src/modules/simulator/` 包（1758 行、8 个完整实现类、54 个全绿测试）成为无人装配的死码；
- 2026-08-27 审计 E2 据此建议"删包+迁测试"。

第一性分析（2026-08-28 会话）推翻了"已替代"的判定：mock 简化版只接管了"定时发消息"的骨架，LLM 驱动的核心能力（人设池加权、四态节奏、上下文消息生成、SC 生成、token 预算）在 v2 中是**净损失**。

## 决策（Decision）

1. **模拟器定位 = 官方开发基础设施**，属于开发工具域（与 Dashboard、`--dry`、日志系统同类），不与生产直播组件争位。装配方式：`[simulator].enabled = true` 时由组合根构造 `SimulatorService` 并纳入生命周期（默认 `false`，生产零沾染）。
2. **概念二分，互补共存**：
   - **回放（replay）**：`mock_collector` 的 jsonl 模式，确定性重放，服务回归测试与 bug 复现——**保留**；
   - **仿真（simulation）**：LLM 驱动的生成式虚拟直播间，服务开发期 Agent 行为锻炼与暴露——**恢复**。
3. **mock 采集器移除 simulator 半吊子模式**（简化泊松 + 硬编码模板 + 双模式字段），"模拟"语义收敛到唯一承载者；修正 `mock_collector.py:229` 的错误注释。
4. **simulator 包清理**：删除 stub（`simulator.py`）与零引用装饰器（`registry.py`）；修复 `service.py` 两处静默吞 `CancelledError`；其余 8 个实现类激活并保留其全部测试。
5. **数据治理与基础设施地位正交**：模拟产生的数据在数据面永远是二等（`simulated` 溯源标记贯穿 payload → 存储贯穿列，§1.6；所有统计查询排除），但模拟器作为工具在开发面是一等（受支持、可装配、可测试）。两者不矛盾。

## 理由（Rationale）

**第一性推导**：Amaidesu 的核心循环需要"活的世界"来锻炼和暴露 Agent 行为，而真实直播间不可随时得。假世界有两种且不可互相替代——固定世界（回放）测确定性，生成世界（仿真）测开放性行为。硬编码 5 句模板对 Replyer 的语境理解零锻炼价值，只有 LLM 生成的、有上下文的消息才能暴露真实行为。因此"LLM 仿真环境"是不可替代的开发基础设施。

**主体性判据检验**（AGENTS.md 红线"谁驱动谁"）：模拟器不采集任何东西（不是采集器），不被调才干活（不是工具）；其四态节奏与观众池**自我驱动**——按判据是 Agent 形态，但它不产生直播内容、服务于开发者而非观众，故归入**开发工具域**，以可选装配的开发服务形态存在，而非业务 Agent。

**对原拍板的再审判**：原拍板正确的部分（两套实现语义混乱必须消除）保留；错误的部分（降级吸收导致能力净损失）翻案。翻案范围精确到"mock 的 simulator 模式"，不波及 jsonl 回放。

## 后果（Consequences）

**正面**：
- 1758 行测试全绿的库代码复活，开发调试主播 Agent 获得生成式测试环境；
- "模拟"一词收敛到唯一承载者，配置面板、测试、注释与实现四方对齐，认知税消除；
- `mock_collector` 职责纯化（确定性回放器），代码量缩减。

**负面 / 代价**：
- LLM 仿真运行产生 API 成本——由既有 token 预算控制器（1h 滑动窗口 + 80%/100% 两级阈值，`token_budget.py`）与 `enabled=false` 默认值双重约束；
- 组合根装配 +1 组件（返回元组 8→9 项），shutdown 链 +1 步。

**防翻烧饼条款**：本 ADR 已钉死"模拟器是开发基础设施"的第一性论证。未来任何"删除模拟器/再度合并进 mock"的提议，必须先推翻本文 Rationale 一节的推导（例如证明"固定世界回放足以锻炼 Agent 开放性行为"），否则视为无效提议。
