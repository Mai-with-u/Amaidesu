# ADR-053：主播的形象工具收成一个 avatar_act（取代 ADR-026 的平台前缀工具面 / 心情慢变 / 按句情绪落地）

- 状态：已采纳；部分取代 ADR-026（已移植到面捕合成器的平台不再暴露"同语义跨平台同名"的前缀工具）与 ADR-052（"工具面不变"一条）
- 日期：2026-10-29
- 实现提交：可用 `git log --grep` 按 subject 检索——`feat(avatar): 统一的形象动作工具 avatar_act`、`refactor(avatar): VTS 不再向 LLM 暴露形象工具`、`feat(avatar): 面捕合成器加心情底色`、`feat(streamer): 快嘴按句带情绪 + 形象按播放时刻切表情`

## 背景（Context）

ADR-026 把三个平台的形象工具收成同名同参数的一组：`*_set_expression`、`*_list_preset_actions`、`*_trigger_preset_action`，外加 VTS 的待机开关。ADR-052 让面捕合成器接管 VTS 之后，这组工具暴露出三个问题：

- **两个来源**：`reply` 已经按句给了情绪，再给 LLM 一个设表情的工具，脸就有两个来源；而且 LLM 把握不了"保持多久、什么时候收"。
- **表达不了有意的身体语言**：点头同意、摇头否定、歪头疑惑，既不是情绪，也不一定是模型作者做好的热键。
- **平台前缀没有意义了**：面捕合成器是唯一持有身体状态的部件。多个平台同时启用时也是同一具身体，按平台分前缀只会让 LLM 在几套入口之间犹豫。ADR-023 当初否决统一入口，理由是"装配期已经路由好，统一入口是多余的一跳"；现在统一入口背后真有一个持有状态的部件，它是唯一正确的一跳。

另外，表情只管一句话，句与句之间形象总是回到同一张静止脸，看不出一阵子的情绪；按句情绪分支（快嘴一次反应拆成两三句、每句带情绪）先前也因"表情会频繁切换"暂缓。

## 决策（Decision）

- **主播的形象工具只有一组，不带平台前缀**：`avatar_list_actions` 与 `avatar_act`，由组合根直接注册的 `AvatarActProvider` 提供，委托面捕合成器执行。目录包括三类：
  - 有意的动作：点头、摇头、歪头、眼睛一亮、吓一跳、皱眉、抬眉、看弹幕；
  - 保持表情：给出 emotion 与 seconds，用来演"假装生气一会儿"这类梗；
  - 各平台登记的动作片段：模型作者做好的动画、贴纸。

  名字写错时，把目录随失败结果一起返回（沿用 ADR-026 的"失败即发现"）。工具组说明提醒主播：平时的表情和小动作形象自己会做，只在想做有意的动作时才调用。
- **平台只登记片段，不再暴露 LLM 工具**：已移植的平台（VTS）连上以后不登记任何 LLM 工具，热键经 `register_clips` 登记到面捕合成器，由 `avatar_act` 按名字转回触发。契约方法（`set_expression` 等）保留给调试台直接调用。还没移植的平台（Warudo、VRChat、表情差分图）暂时保持 ADR-026 的前缀工具。
- **工具页的降级判定**：提供者卡片带上连接态。报告"已连接"的 0 工具提供者不算降级，以便区分"连着但不暴露工具"和"没连上"。
- **心情**：面捕合成器新增两个慢变维度，即愉快度和兴奋度。
  - 每个表情上脸时按情绪推一下，礼物、受惊等脉冲轻推一下；
  - 没有新刺激时按半衰期（默认 90 秒）回到人设基线；
  - 心情作用在所有表情之下：影响静止嘴角与眉、睁眼程度、头部微动幅度、眨眼频率。
- **按句情绪落地**：快嘴一次反应可以输出两三行"情绪：台词"，分成几句、按段落逐句播放。面捕合成器本来就是每句等开始播放才上脸，相近情绪由调度规则合并；未移植平台靠"等播放再切"标记对齐播放时刻。

## 替代方案（Alternatives）

- **保留 `vts_*` 前缀工具，另加程序化动作**：两套入口做同一件事，模型会在两者之间犹豫；热键与程序化动作本来就该在同一个目录里。被否决。
- **新动作工具挂在 VTS 适配器上**：多平台同时启用时，动作只会落在一个平台上，也违背"身体只有一个"。被否决。
- **把心情交给 Planner 用工具设置**：心情是累积出来的，不是决定出来的。让 LLM 维护它，既费上下文，又容易前后不一致。被否决，心情只由事实累积。
- **按句情绪继续暂缓、只收紧拆行提示词**：实测模型约一半反应会拆行。拆行本身是对"情绪转了"的如实表达，频繁切换的问题已经由调度规则在形象层解决，没有必要压制。

## 后果（Consequences）

- 主播的形象工具从"每个平台 3~4 个"收成 2 个。设表情这条路只剩 `reply` 的情绪，保持表情是唯一的例外，要显式给出秒数。
- VTS 在工具页显示为"已连接、0 工具"，不再标降级。
- 句与句之间的静止脸随心情变化：连着几句开心的话后静止时也带着笑，打累了动作会慢下来。
- 代价：
  - 还没移植的平台仍是两套工具面并存，全部移植后才能删掉 ADR-026 的前缀工具和 `speech_binding`；
  - 主播得先查目录才知道有哪些片段，好在名字写错时会附带目录，能自行纠正。
