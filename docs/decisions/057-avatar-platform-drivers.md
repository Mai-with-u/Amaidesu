# ADR-057：Warudo、VRChat、表情差分图也改由面捕合成器驱动（收尾 ADR-052 / ADR-053 的过渡安排：Warudo 伪装成 iFacialMocap / VRChat 走官方眼动与 VRCFaceTracking 参数 / 删掉旧的情绪订阅与前缀工具）

- 状态：已采纳；取代 ADR-052 与 ADR-053 中"尚未移植的平台保持原样，继续走旧的情绪订阅和平台前缀工具"的过渡安排，其余不变
- 日期：2026-10-30
- 实现提交：与本篇同笔交付（`git log -- docs/decisions/057-avatar-platform-drivers.md`）；各平台的移植见 `git log --grep "面捕合成器" -- src/modules/avatar/platform`

## 背景（Context）

ADR-052 让面捕合成器每秒 30 帧合成"此刻脸和身体的样子"，平台适配器缩成只写参数的驱动，VTS 先行；Warudo、VRChat、表情差分图当时暂缓，仍订阅发言事件、按情绪一次性写参数（`speech_binding`），并保留各自带平台前缀的设表情、列动作、触发动作工具。暂缓的理由是 3D 模型还不可用。

两条路并存的代价是：同一句话在 VTS 上有起落、有眨眼和眼神，在其他平台上是一张定格的脸；主播看到两套动作工具；Warudo 的表情档案、状态件和眨眼、移眼、点头三个固定节奏的后台任务互相覆盖，每个表情键一条 WebSocket 消息，也承受不了逐帧发送。

移植并不依赖具体的 3D 模型：ADR-054 已经把面捕合成器的一帧定成面部捕捉的通行规范（ARKit 系数），而 Warudo 和 VRChat 都有接收这套规范的现成入口。

## 决策（Decision）

- **Warudo**：驱动按 iPhone 面捕 App iFacialMocap 的 UDP 格式把每一帧（52 个 ARKit 系数、头部转角、眼球转角）发给 Warudo 自带的 iFacialMocap 接收器（默认 127.0.0.1:49983）。Warudo 把面捕合成器当成一部 iPhone，用自己的面捕流程（标定、平滑、形状映射）落到模型上；模型怎么映射在 Warudo 的面捕设置里调。WebSocket 蓝图通道只留给动作片段（头部动作、站姿、抛鱼、登记的蓝图动作）和风格化标记。表情档案、状态件、后台任务、元音口型渲染退役，`avatar.toml` 2.0.44 删掉相应的键。
- **VRChat**：眼睛写 VRChat 官方的 OSC 眼动输入（任何形象都认）；脸按 VRCFaceTracking"统一表情"第二版的简化参数名换算 ARKit 系数，只发变化了的值，没做面捕参数的形象由 VRChat 忽略；风格化标记写形象参数。头部转动 VRChat 不开放写入，不做。
- **表情差分图**：不挂逐帧驱动（整张图画不出强弱、眨眼和口型），小部件页按面捕合成器此刻的主表情换图。
- 所有平台适配器都不再向 LLM 暴露工具，平台上做好的动作登记为片段经 `avatar_act` 触发；`set_expression` 等契约方法只留给调试台，一律交给面捕合成器。旧的情绪订阅 `speech_binding` 与只为前缀工具服务的公共件删除。

## 替代方案（Alternatives）

- **Warudo 保留 WebSocket，每帧合成一条消息由蓝图拆开写入**：要为每个模型生成"拆包 + 写形状"的蓝图，等于在蓝图里重做一遍 Warudo 已有的面捕流程（平滑、映射、头部骨骼），换模型还得重生成。
- **Warudo 用 VMC 协议**：VMC 的表情通道传的是模型自己的表情名，模型相关的映射又回到了我们这边；iFacialMocap 传的就是 ARKit 系数，和面捕合成器的词表一致。
- **用 Warudo 的脚本扩展写专用接收器**：控制力最强，但要维护一段 C# 代码，且同样要自己做映射。
- **VRChat 只写眼睛**：大部分形象确实只认眼动输入，但做了面捕的形象几乎都用 VRCFaceTracking 的参数名；多发的参数被 VRChat 忽略，代价只是本机 UDP 流量。
- **等可用的 3D 模型再移植**：移植只依赖协议，不依赖模型；继续并存的代价（两套工具、定格的脸）每场直播都在付。

## 后果（Consequences）

- 四个平台共用同一个面捕合成器：同一句话在哪个平台上都有同样的起落、眨眼、眼神与心情，调校页调的参数对所有平台生效，可以同时开几个平台。
- 主播只看到 `avatar_act` / `avatar_list_actions` 一组形象工具。
- Warudo 的接入方式变了：要在 Warudo 里把角色的面部捕捉设成 iFacialMocap、关掉音频口型；以前生成的表情、口型、眨眼蓝图要删掉。麦麦这类表情做在自定义形状上的模型，要么补上 ARKit 形状，要么在 Warudo 的形状映射里逐项接，原来的麦麦表情档案不再使用。
- iFacialMocap 与 VRChat 眼动输入的方向约定按协议与常见用法推定，未在真机上核对；左右反了时 Warudo 接收器可勾镜像，VRChat 视线方向随直播镜头位置而定。
- 发言事件上的"等播放再切表情"标记失去了最后一个消费者（面捕合成器本来就按播放时刻上脸），仍作为发言事实保留在事件里。
