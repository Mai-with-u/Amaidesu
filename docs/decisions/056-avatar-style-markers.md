# ADR-056：面捕合成器加一组风格化标记（扩展 ADR-054 的词表：漫符自定名 / 配方照惯例挂 / 平台配置登记对应资源）

- 状态：已采纳；扩展 ADR-054（规范词表之外加一组自定名的标记，规范部分不变）
- 日期：2026-10-30
- 实现提交：与本篇同笔交付（`git log -- docs/decisions/056-avatar-style-markers.md`）

## 背景（Context）

ADR-054 把面捕合成器的通道换成面部捕捉的通行规范：ARKit 52 个表情系数、VRM 5 个元音口型、头部与身体姿态。规范描述的是真人的脸，动漫模型的表现力有一块它覆盖不了：画好的漫符——脸红、眼泪、汗滴、黑线、生气的青筋、惊吓符号、爱心眼、星星眼、阴影脸。哭的时候没有泪、害羞时不脸红，动漫角色就少了最直白的一层表情。

这些东西没有通行规范：ARKit 没有，VRM 1.0 只把它们留给自定义表情，Live2D 和 VBridger 也没有统一名字。模型上的形态也不一样：VTS 自带的 akari 把眼泪、爱心眼、生气符号做成表情文件（`.exp3.json`，整体开关，VTS 负责淡入淡出）；约稿时更好的做法是做成 0~1 的参数，能随表情渐入渐出。

## 决策（Decision）

- 面捕合成器的词表加一组风格化标记，名字由我们定：blush（脸红）、tears（眼泪）、sweat（汗滴）、gloom（黑线）、anger（生气符号）、shock（惊吓符号）、heart_eyes（爱心眼）、star_eyes（星星眼）、shadow（阴影脸）。通道名带 `marker_` 前缀，取值 0~1，静止时为 0。
- 标记只来自表情配方，和其他通道一样乘情绪强度、跟着表情的起持落走。默认配方照动漫惯例挂：害羞、尴尬、爱意脸红，哭有泪（难过只有一点），生气冒青筋，惊、怕出惊吓符号，无语出黑线，兴奋星星眼，嫌弃阴影脸。人设覆盖可以改。
- 模型上有哪些标记、对应什么，由平台配置登记，没登记的不发。VTS 的 `[platform.vts.markers]` 两种写法：以 `.exp3.json` 结尾的是表情文件，值越过 0.35 打开、落到 0.2 以下关上（回差防抖），只在开关变化时发一次；其余按 VTS 输入名逐帧写 0~1，VTS 里没有的由适配器补建。连上和换模型时读一遍模型的表情文件清单，登记了但模型上没有的点名跳过。

## 替代方案（Alternatives）

- **配方直接写平台资源名**（如"crying 打开 EyesCry.exp3.json"）：配方会绑死某个模型和平台，换模型就要改配方，违背 ADR-054"模型的个性走配置"的分工。
- **全部做成动作片段，让主播用 avatar_act 触发**：漫符是情绪的一部分，不是有意的动作；靠主播记得"哭的时候顺便触发眼泪"不现实，也和表情的起落脱节。
- **不设固定词表、标记名随模型自由定**：默认配方就没法挂标记，每个模型都得从头写配方。

## 后果（Consequences）

- 有漫符的模型登记几行配置，哭、害羞、生气时就能自动出现对应漫符；没登记时行为与之前完全一样。
- 词表是我们自定的，Warudo、VRChat 等平台移植时各自加同样的"标记 → 平台资源"登记，不需要改配方。
- 表情文件只能整体开关，弱情绪下看不到；想要随强度渐变，需要模型作者把漫符做成参数。
- 标记和 VTS 热键可能指向同一个表情文件，两边同时用时以后发的为准。
