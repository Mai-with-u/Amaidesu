# 039 场次回看事件侧以诊断事件流为事实源

**状态**：已采纳
**日期**：2026-10-12
**实现提交**：`git log -- docs/decisions/039-event-replay-diagnostics-source.md`（与实现同批交付于 task/event-replay-console 分支，含 `session_events.py` 读取面与控制台回看接线）

## 背景

直播控制台的回看（`GET /live-sessions/{id}/timeline`）长期与实时视图存在调试体验落差：事件侧只来自内存环形缓冲（5000 条、重启即清）且仅收 7 类事件，工具卡、裁决卡、递话、Agent 响应等在回看中全部缺失。同时，`EventHistoryRecorder` 早已订阅全部事件并经 `DiagnosticsWriter` 逐小时落盘到 `logs/events/`（覆盖面 ⊇ 实时 WS 广播面），但这份数据自我定位为"可丢弃旁路"，默认 14 天滚动删除，从未被任何产品面消费。

用户诉求：回看仅用于诊断（回看当时信息、找出问题、修复问题），让诊断数据真正用起来；不做历史干预。

## 决策

1. **回看事件侧的事实源 = 诊断事件流文件（logs/events）∪ 内存环形缓冲**，按记录 id 去重合并，白名单与实时 WS 卡面对齐。读取面 `SessionEventReader`（dashboard/services/session_events.py）按场次（`data.live_session_id`）与时间范围扫描逐小时 JSONL；诊断文件缺失/损坏一律降级为空并如实回报（`events_pruned`），不抛错。
2. **诊断正文默认不滚动删除**：`[diagnostics].retention_days` 默认 14 → 0（0 = 永不清理，语义已存在）；用户显式设置正整数才启用清理。存量配置文件不迁移——旧值 14 在新代码中仍合法且语义不变，由用户手动跟随（本机改 0 或设置页改），CHANGELOG 说明。WebUI 应用日志（LogStreamer 落盘）的硬编码 14 天默认同批改为 0。
3. **删除即降级**：用户手动清理 `logs/` 天目录后，对应时段回看自动退化为明细行视图（弹幕/发言/礼物/SC，存于 SQLite，不受诊断清理影响），页面提示降级原因。不为回看新增任何持久化表或双写。
4. **思考内容不落事件流**：实时思考流（`thinking.delta`）维持 best-effort 直推 WS 的定位（ADR-008），不落盘；回看时决策/裁决/响应卡按 `llm_request_id` 从 LLM 请求历史懒取 `reasoning_content`（出库正文合并回供已是既有能力），形态为按请求整段推理而非逐 token 流。

## 替代方案

- **事件侧另立持久化表（SQLite events 表或消息流复制）**：被否。诊断流已是全量事件、逐小时文件天然支持按时间窗扫描；另立表 = 双写双真相，且把"观察面旁路"升格为存储域契约，违背数据流边界（采集器只发布、观察面只读旁路）。
- **升级版本 + 迁移钩子把存量 retention_days=14 改写为 0**：被否。AGENTS.md 数据变换档的触发前提是"旧值会被误读、系统正确性依赖存量跟随"，本变更不满足（14 仍合法、语义不变、删除即降级是既定设计）；且"值==14"无法区分旧默认物化值与用户显式值，钩子会把显式选 14 的部署静默翻转。本机手动改值 + CHANGELOG 说明即最小必要机制。
- **为回放重放思考流而把 thinking.delta 落盘**：被否。delta 粒度落盘成本高（逐 token），且该流是视图层 best-effort 观测通道，落盘改变其定位；按请求整段的 `reasoning_content` 已在 LLM 请求历史中，诊断价值等价。

## 后果

- 回看与实时呈现同一卡面（工具/决策/裁决/阶段/游戏/递话/响应），跨重启不丢事件侧；控制台成为可用的诊断工具。
- `logs/` 目录默认无限增长（事件流 10-20MB/场 + LLM 正文更大头），空间管理责任移交用户——嫌占空间手动删天目录，删除后回看自动降级，系统不阻止也不告警。
- 依赖盖章覆盖面：事件记录按 `data.live_session_id` 过滤，凡载荷声明该字段即被盖章（字段驱动、不限域），新增回看收录类型时须核对其 payload 是否声明 `live_session_id` 字段。
- 保留期变更只影响新生成的配置文件；存量部署的 `retention_days=14` 保持原值，需要长期回看的部署须手动改为 0。
