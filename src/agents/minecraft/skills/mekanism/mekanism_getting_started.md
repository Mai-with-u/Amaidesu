# 通用机械（Mekanism）起步

Mekanism 的机器几乎都要 **钢制机壳** 和 **电力**。起步就是把这两样打通，之后的机器只是换配方。

## 起步路线

1. **锇**：找锇矿（主世界常见的蓝灰色矿石）并熔炼成锇锭，它是钢制机壳和许多部件的原料。
2. **冶金灌注机**：最先造的机器，用来做钢（铁 + 碳）与灌注合金（铜 + 红石）等。灌注机自身靠电运行，所以电力要和它一起准备。
3. **钢制机壳**：由钢、锇与玻璃合成，是基础机器的通用外壳，批量做几个备用。
4. **基础机器**：富集仓（矿物 2 倍）、电力冶炼炉、粉碎机，按当前需求挑，不一次全造。

每一步的精确配方以当前整合包为准：先查 `maicraft_perceive(view="knowledge", query=物品名)`，再读 `maicraft://knowledge/recipes/...`；整合包常改配方，不要凭记忆硬做。

## 电力从哪来

- **Mekanism 本体没有常规发电机**，发电机在附属模组 Mekanism Generators（命名空间 `mekanismgenerators`）。装了它就从热力发电机（烧燃料或岩浆）、太阳能、风力起步。
- 没装发电机附属时，找整合包里其他模组的 FE 发电方式，或接入现场已有的授权电网；外部能量接入在蓝图里声明为 `energy` 类外部输入。
- 用能量立方缓存电力，用通用线缆连接；先保证机器有电，再追求产量。

## 机器的面与自动化

- Mekanism 机器的每个面可以配置输入、输出与自动弹出。机器建好后先用 `maicraft:inspect_machine` 看它实际的面配置与库存，再决定是否修改；配置走机器操作能力，具体可用项以 `inspect_machine` 返回的原生契约为准，依赖服务端协助时按回执里的可用性处理。
- 先手动投料验证机器能产出，再接管道做自动化。

## 常见坑

- 只造了机器忘了电：机器不工作先看能量缓冲是不是空的。
- 灌注机里的灌注物（碳、红石等）和主料是两个槽，缺任何一种都不产出。
- 主播禁用了某个 Mek 附属时，把对应命名空间写进蓝图 `constraints.forbidden_mods`。

## 何时上报

整合包里找不到任何可用的发电方式、或关键原料（锇等）在可达范围内找不到时，上报主播。
