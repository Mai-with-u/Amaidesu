# 通用机械：矿物倍增

倍增链是“用更多机器与化学品换更多锭”。每升一级都要新增一套设施，先确认产量需求值得，再升级。

## 各级概览

| 倍率 | 核心机器 | 额外需要 |
| --- | --- | --- |
| 2 倍 | 富集仓 | 只要电 |
| 3 倍 | 净化仓 | 氧气（电解分离器分解水） |
| 4 倍 | 化学压射室 | 氯化氢（化学灌注器合成氢与氯） |
| 5 倍 | 化学溶解室、化学清洗机、化学结晶器 | 硫酸等更多化学品与清水 |

每一级的输入输出（矿石、原矿、碎块、粉、晶体的换算）以当前整合包配方为准：用 `maicraft_perceive(view="knowledge", query=机器或产物名)` 找到条目再读配方，不凭记忆写死比例。

## 推进顺序

1. **先稳定 2 倍**：富集仓 + 电力冶炼炉，就能把矿变成粉再烧成锭；这一级投入最小，收益立刻可见。
2. **需要大量某种金属时再上 3 倍**：电解分离器 + 净化仓，附带解决氧气来源（水源要持续）。
3. **4 倍、5 倍是工程项目**：化学品链条长、机器多、耗电大，适合作为一档直播的大目标，先和主播确认再开工。

## 施工与运行

- 每台机器都要钢制机壳与电力，起步问题见《通用机械起步》。
- 链条上的机器按“上一台的输出面接下一台的输入面”排列；建好后用 `maicraft:inspect_machine` 核对面配置与库存，再手动投一批矿验证整条链有产出。
- 化学品管道（加压管道）与物品管道是不同部件，接错不会报错但没有产出。

## 常见坑

- 只升级了机器没补化学品，机器满电却不工作。
- 把原矿与矿石方块混为一谈：二者在部分配方里倍率不同，以配方查询为准。
- 一次性搭到 5 倍却没有足够电力，整条链断断续续，不如先把低一级跑满。

## 何时上报

升级到 4 倍及以上前先上报主播确认（耗时长、占地大）；化学品原料在可达范围内拿不到时也上报。
