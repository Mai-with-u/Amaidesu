# 机械动力：动力网

Create 机器靠旋转动力工作：动力源提供**应力容量（SU）**，机器按转速消耗应力。总消耗超过容量整网停转（过载）；转速不够某些机器不工作或很慢。

## 先接入，再自建

1. **找现成动力**：用 `maicraft_perceive(view="kinetic_sources", query=短名称或ID)` 找附近已加载的动力接口。候选只说明“这里有动力”，不授权取用——只接本次施工范围内或已知公共的网络，不接隔墙、地下或别人的网。
2. **接线**：已有动力源与目标都记过名字时，用 `maicraft:connect_mechanical_power`（`source_label` 必填，不会自动挑最近的源）。验收看回执里的 `power_ready` 与两端转速证据，接通不等于机器产量达标。
3. **自建动力源**：附近没有可用动力时，把动力源作为机器蓝图的一部分设计（见《机械动力：机器从需求到产出》）。

## 动力源怎么选

| 动力源 | 适合 | 注意 |
| --- | --- | --- |
| 水车 | 开局、河边，稳定 | 需要流动的水接触叶片 |
| 风车（风车轴承 + 帆） | 需要较大应力且场地开阔 | 帆数量决定应力；需要手动启动轴承 |
| 蒸汽引擎 | 中后期大功率 | 需要锅炉、水源与持续热源 |

**不使用创造马达**等创造模式物品，也不依赖世界里已经放着的创造动力。动力源具体的应力数值与组装方式以 Ponder 和方块说明为准（`maicraft://knowledge/block/create/<方块>`、`maicraft://knowledge/ponder/index`）。

## 转速与应力

- 齿轮箱、大小齿轮可变速与换向；提速会成倍提高下游应力消耗。
- 一台机器转不起来先查：网络是否过载、转向是否反、转速是否达到机器要求，而不是先拆重建。
- 多台机器共用一个网时先估总消耗，过载就分网或加动力源。

## 常见坑

- 把 Ponder 演示里的创造马达当成必须照搬的部件：它在教程里只表示“这里需要动力输入”。
- 只看静态结构就宣布机器能用：以真实转速与产出为准。
- 链式传动每台机器有数量限制，拆成多次接线也不会重置额度。

## 何时上报

附近没有可授权的动力且自建所需材料拿不到，或现有公共网络接入会让别人的机器过载时，上报主播定夺。
