# 机械动力：动力网

Create 机器靠旋转动力工作：动力源按转速提供**应力容量**，机器按转速消耗应力（转速 n 时两边都乘 n）。整张网的消耗超过容量就整网停转（过载）；转速不到某台机器的门槛，它不干活或很慢。

## 先接入，再自建

1. **看现场**：`machine_inspect(target=机器的一格)` 看这台机器挂没挂在网上、转不转；`networks` 里那张应力网的读数（容量 `stress_capacity`、当前应力 `stress`、转速）说明它还够不够用。
2. **接现成的网**：`machine_connect(target=机器, network=kinetic)`。不给 `source` 时在 `radius` 里找挂着应力网的格子，在转的机器旁边那格优先；要接指定的那张网，`source` 给它的观察编号、坐标或记过的地点。线路由 Mod 规划：近处传动杆，拐弯齿轮箱，远处从来源网里已有的链条输送机跨过来；只铺在空格里，不挖方块，缺料自己去拿。
3. **验收**：回执分开给 `joined`（两端在不在同一张网）和 `running`（接上了转不转），`summary` 是那张网现在的读数，`route` 是这次铺的每一格。接上了但转速为 0 或过载，说明线路是通的、动力那边不够；接通也不等于机器产量达标，产量看《机械动力：机器从需求到产出》的试运行。
4. **自建动力源**：附近没有能接的网（`NOT_FOUND`），或机器离哪张网都远又要长期运转，才把动力源当成机器蓝图的一部分来设计，用 `machine_build` 施工。

只接本次施工范围内的网，或主播说过能用的公共网；隔着墙、在地下、别人家的网，主播没点头不接。

## 动力源怎么选

| 动力源 | 适合 | 注意 |
| --- | --- | --- |
| 水车、大水车 | 开局、河边，稳定 | 要流动的水推叶片，静水不转 |
| 风车（风车轴承 + 帆） | 场地开阔、要较大应力 | 帆越多容量越大；帆装好后要 `use` 点一下轴承才转 |
| 蒸汽引擎 | 中后期大功率 | 要流体储罐当锅炉、持续供水与热源 |
| 手摇曲柄 | 手动做几件 | 不适合长期产线 |

**不用创造马达**等创造模式物品，也不依赖世界里已经放着的创造动力。每种动力源每转给多少容量、自己转多快，读它的机器资料（总览 `maicraft://knowledge/machine/create/index` 里列着地址）；资料里写“进世界后读得到”的就进世界再查，不凭记忆写数。

## 算账：转速与应力

- 设计阶段用 `machine_review` 的 `power`：把蓝图里每格吃的应力与动力源给的容量各加起来，消费不超过容量才转得动。变速齿轮会改这笔账，所以它只是估计；蓝图里没有动力源时它会说容量要靠接现场的网。
- 大齿轮带小齿轮提速，反过来降速；提速会同比提高下游每台机器吃的应力。
- 多台机器共用一张网时先估总消耗，过载就分网或加动力源。

## 机器不转先查什么

- `machine_inspect` 看 `running`：转速是 0，还是在转但不到门槛。
- 看 `networks` 里那张网是不是过载（`stress` 超过 `stress_capacity`）。
- 转向：粉碎轮这类成对的机器转向要相反。
- 两端不在同一张网：看接线回执的 `route` 和 `machine_inspect` 的读数找断点。

查清楚再改，不先拆重建。

## 常见坑

- 把思索演示里的创造马达当成必须照搬的部件：它在教程里只表示“这里接动力”。
- 只看静态结构就宣布机器能用：以 `running` 读数与真实产出为准。
- 一台机器里链条输送机的个数有上限（实例配置，默认 1），拆成多次接线也不会重置额度；近处能用传动杆接上的就别用链条。
- 线路找不到全是空格的走法会以 `NOT_POSSIBLE_HERE` 停下：清出一条路、换个 `source`，或自己写蓝图用 `machine_build` 铺。

## 何时上报

附近没有可用的动力且自建所需材料拿不到，或接入公共网会让别人的机器过载时，上报主播定夺。
