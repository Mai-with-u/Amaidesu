# 采矿：铁与钻石

采矿要的是“稳定拿到足量矿物并活着回来”，不是挖出最深的洞。

## 先定目标数量与深度

- 先说清要什么、要多少：铁通常 1～2 组起步，钻石按用途算（镐 3、全套装备 24）。
- 各种矿最多的那一层（1.18 以后的分布；`obtain` 长程挖矿就挖到这一层）：

  | 矿 | 生成范围 | 最多的那层 |
  | --- | --- | --- |
  | 铁 | Y -64～320（高山 Y≈232 还有一批） | 16 |
  | 金 | Y -64～32 | -16 |
  | 钻石 | Y -64～16 | -59 |
  | 红石 | Y -64～15 | -58 |
  | 青金石 | Y -64～64 | 0 |
  | 铜 | Y -16～112 | 48 |
  | 煤 | Y 0～320 | 95 |

- Y 0 以下是深板岩层，挖得更慢，需要更好的镐。绿宝石只在山地、越高越多；下界的矿和模组矿不在表里。细节见 `maicraft://knowledge/game_mechanics/ore-heights`。

## 取矿方式

- 用 `obtain` 要矿物或它的产物（`minecraft:raw_iron`、`minecraft:diamond`）。附近**看得见**的先挖，埋在石头里的不算（不透视）。
- 附近看不见上表里的矿时，`obtain` 会自己长程挖矿：在那一层之上就挖三格高的台阶下去，到了那一层转个向挖两格高的通道（已经在那层以下、还在范围里就原地横挖），每走一步看一眼，看见了就整脉挖了捡起来；横着挖满 64 格还没看见会如实停下。要许可 `change_blocks` 至少 `natural`。在生成范围以下（要往上爬）不挖。
- 装了 FTB 连锁破坏时，挖矿脉、开台阶和通道都按住连锁键一下挖一大片；连锁那一批有一格挨着水或岩浆、不许挖，就只挖那一格。
- 长程挖矿停下（挖满一段没看见、前面挨着水或岩浆）后，换个方向或换个地方再要一次；也可以先用 `travel` 去洞穴、峡谷这类露矿多的地方。
- 要铁锭就直接要铁锭：角色会先拿粗铁再去烧，缺镐、缺燃料、缺熔炉都会先自己补。
- 手上的镐不够格时，`obtain` 会先备工具；要一次挖一格指定的方块用 `gather`，它不会自己备工具，缺什么会写清楚。

## 安全线

- 带足食物、备用镐再下深处；生命低于一半先退回亮处恢复。
- 岩浆附近不挖脚下与头顶的未知格，挖穿隔挡前看流向（`maicraft://knowledge/game_mechanics/fluid-flow`）。
- 砾石、沙子会塌，挖下方方块前留意（`maicraft://knowledge/game_mechanics/gravity-blocks`）。
- 以上资料用 `maicraft_lookup`（`topic=knowledge`）按 `id` 读。

## 收尾

- 回据点用 `deposit` 存放，或交付前核对背包实际数量；矿物掉率与时运会影响产量，几次不掉不是故障（`maicraft://knowledge/game_mechanics/drop-rates`）。

## 何时上报

换了两个以上方向仍看不到目标矿、或镐等级不够且无法就地补足时，把已去过的地方、已有材料与卡点上报主播。
