# 原版通关路线

通关是一串里程碑，不是一次任务。每段都有自己的准备、许可与验收，按段推进，段与段之间向主播汇报进展——这本身就是直播内容。没有“一下推进到某个里程碑”的能力：每段由你拆成几个目标（`obtain` 备料、`travel` 过门、`fight` 打龙……），读完结果再下一步。

## 里程碑与准备

| 段 | 目标 | 进入前至少具备 |
| --- | --- | --- |
| 铁器时代 | 铁镐、铁剑、铁甲、盾牌 | 稳定食物与据点（见《生存开局》） |
| 钻石 | 钻石镐（挖黑曜石要它） | 铁镐、火把、足量食物（见《采矿》） |
| 下界 | 进入下界 | 打火石；黑曜石十块，或附近有岩浆池；铁甲以上 |
| 烈焰棒 | 在下界要塞拿到烈焰棒 | 盾牌、弓箭或好剑、食物、回程的门记了名字 |
| 末影珍珠 | 够做末影之眼的珍珠 | 打末影人，或跟牧师村民买 |
| 要塞 | 亲眼看到末地门框架 | 末影之眼：十二个框里缺几只备几只 |
| 末影龙 | 打败末影龙 | 剑或斧、弓和一组以上的箭、好甲、大量食物、方块、满血 |
| 回主世界 | 走出口门回家 | 龙已死、出口门亮着 |
| （可选）鞘翅 | 外岛末地船上的鞘翅 | 末影珍珠、方块，能打潜影贝 |

## 每段用什么

- **备料**：铁装、钻石镐、打火石、末影之眼都用 `obtain` 直接要成品，它按真实配方自己备原料。烈焰棒、末影珍珠要打怪：`obtain(item=minecraft:blaze_rod, via=hunt)`、`obtain(item=minecraft:ender_pearl, via=hunt)` 只打已加载的那几只，附近没有就先 `travel` 过去，或给 `max_distance` 让它出去找一圈；许可不够时结果会写明卡在哪一项。买珍珠用 `via=trade`。
- **下界**：`travel` 目标写 `{"kind":"dimension","name":"minecraft:the_nether"}`。附近有活门就走进去；没有就补残框、摆黑曜石，或在岩浆池岸浇一扇（默认 `change_blocks=natural` 就能建，`none` 时不建门）。到了先用 `remember` 把落点的门记个名字，回程照它。
- **下界要塞**：`explore` 的 `interests` 写 `minecraft:fortress` 跑一趟，路过看见会记下线索；再 `find(structure=minecraft:fortress)`，到了附近亲眼确认，然后打烈焰人。
- **要塞**：没有扔末影之眼指路的能力，要塞要亲眼看见过末地门框架才记得下线索。`find(structure=minecraft:stronghold)` 先按记过的线索找，没线索就看眼前这一片有没有末地门框架（只在要塞里有）。要塞埋在地下，地表跑图看不出来：主播知道大概位置就问一句，`travel` 过去再下到地下找；矿道、洞穴里撞见石砖走廊也值得进去看看。看到框架后用 `remember` 记个名字。
- **去末地**：`travel` 目标写 `{"kind":"dimension","name":"minecraft:the_end"}`，`permissions.use_rare_items` 设为 true（插眼要用末影之眼）。它按记过的要塞线索走到末地门房间，缺几只眼先备几只，逐格插上，门开了进去。**末地门是单程**：进去之前备齐打龙的东西。
- **打龙**：在末地下 `fight`，点名龙（`observe` 拿到它的 e#）或不点名（`entity` 不给）都按龙的打法来：引擎自己先射水晶、躲龙息和冲撞、龙趴下时砍头、飞着时射、血到 6 颗心退开吃东西回血。你要做的是开打前备好装备、打完读结果。铁栏笼里的水晶它射不进去，会写明在哪；要不要搭上去拆一根铁栏由你定（`build` 搭到笼边、`gather` 拆一根，再下 `fight`），不拆照样能打赢。
- **回主世界**：龙死后出口门亮了，`travel` 目标写 `{"kind":"dimension","name":"minecraft:overworld"}`，它会走出口门回去，落在重生点（床边，没床是世界出生点）。门没亮说明龙还没死：它不代打，也不去找别的门。
- **去外岛**：每打败一次龙，主岛外圈开一扇折跃门。`travel(via=end_gateway)` 不给目标就是过最近的一扇；目标给外岛的坐标，就过门后接着走过去。过门要对着门洞扔一颗末影珍珠，所以要 `use_rare_items`，身上没有珍珠会先去弄。回主岛一样扔一颗；人在外岛直接下回主世界的 `travel`，会先过门回主岛再走出口门。

## 外岛：末地城与鞘翅

末地城里找鞘翅、从展示框取下来没有现成的能力，由你分几步规划：

1. 到外岛后 `explore` 的 `interests` 写 `minecraft:end_city`，或直接 `find(structure=minecraft:end_city)`；紫珀块成片的就是，用 `remember` 记下。
2. 鞘翅挂在末地船（城边悬空的那艘船）船尾房间的展示框里。走到附近后 `find(entity=minecraft:item_frame)` 找展示框，或进船尾房间 `observe`；`observe(what=detail, id=e#)` 确认框里是鞘翅。
3. 展示框右键（`use`）只会转动里面的东西，取不下来；原版要打一下展示框。可行的办法是挖掉展示框贴着的那一格（展示框朝外，背后那格就是）：用观察编号点名它下 `gather`，展示框连鞘翅一起掉下来，再 `gather` 捡起掉落的鞘翅（e#）。挖之前先 `execute(dry_run=true)` 看许可够不够。
4. 船上和城里有潜影贝，被它打中会飘起来，飘着时别待在虚空边上。先 `fight` 清掉附近的（默认许可就能打敌对生物），再去取。
5. `observe(what=self)` 看鞘翅真进了背包才算拿到，再用 `travel` 回主岛、回主世界。

## 许可

- `use_rare_items`：插末影之眼、扔末影珍珠过折跃门要用掉稀有消耗品，这项许可默认是 false。目标本身就是去末地、去外岛时直接设为 true，不为这个再问主播；结果里会记用掉了几只眼、几颗珍珠。
- `fight`：默认 `hostile_mobs` 就能打末影龙、烈焰人、潜影贝。末影人、僵尸猪灵这类中立生物没惹毛时不打，清怪时也不算进去。
- `change_blocks`：建下界门、搭桥、挖展示框背后那格都受它管，默认 `natural`。要拆别人的东西才需要 `any`，没有主播明确同意不用。

## 段间节奏

- 每完成一段用 `minecraft_report` 交付一次简短总结（拿到了什么、下一段打算），让主播有话可讲；不要攒到最后才说。
- 进下界、末地这类危险段之前，用 `remember` 把据点、传送门位置记好。
- 回执区分“看到了”和“做到了”：找到要塞线索不等于激活了门；`fight` 的 `defeated` 里有龙、`dragon.defeat` 里有死亡证据才算打赢，龙飞远不见了只记进 `lostTrack`；鞘翅以真进了背包为准。
- 死亡后先回据点补给，再判断是否继续当前段；装备掉在危险处时把“去不去捡”作为选项上报。

## 常见坑

- 末地、下界里的床一点就炸，`use` 也不会去点。
- 打龙缺弓和箭、或剑斧都没有，`fight` 开打前就以 `NEED_ITEM` 结束，写明缺什么、水晶在哪：补齐再来，不硬打。
- 打龙途中血回不上来：身上没吃的是 `NEED_ITEM`，有吃的还回不上是 `DANGER`，回来补给。五分钟龙一次没趴下也没射中什么是 `STUCK`，结果写着龙在干什么、还剩几颗水晶。
- 戴上雕刻南瓜就不怕和末影人对视。
- 下界里迷路是常态：从传送门出发就记地点，不要只凭感觉往回走。
- 下界与末地之间没有原版门，要经主世界中转。

## 何时上报

需要但没有拿到上述许可、要塞怎么都找不到线索，或同一段连续两次死亡时，带上装备与卡点上报主播，请主播决定是加强准备还是换目标。
