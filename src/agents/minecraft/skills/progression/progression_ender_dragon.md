# 原版通关路线

通关是一串里程碑，不是一次任务。每段都有自己的准备、授权与验收，按段推进并在段与段之间向主播汇报进展——这本身就是直播内容。

## 里程碑与准备

| 段 | 目标 | 进入前至少具备 |
| --- | --- | --- |
| 1. 铁器时代 | 铁镐、铁剑、铁甲、盾牌 | 稳定食物与据点（见《生存开局》） |
| 2. 钻石 | 钻石镐（挖黑曜石必需） | 铁镐、照明、足量食物（见《采矿》） |
| 3. 下界 | 点亮下界传送门并进入 | 黑曜石（或岩浆浇铸）、打火石、铁甲以上 |
| 4. 烈焰棒 | 在下界要塞拿到烈焰棒 | 盾牌、弓箭或好剑、食物、回城路线 |
| 5. 末影珍珠 | 足够做末影之眼的珍珠 | 击杀末影人或与猪灵交易（金锭） |
| 6. 要塞 | 找到要塞并激活末地传送门 | 末影之眼若干（投掷与填框都会消耗） |
| 7. 末影龙 | 击败末影龙 | 好装备、弓箭、大量方块、食物、满血 |
| 8.（可选）鞘翅 | 末地城船上的鞘翅 | 末影珍珠（穿折跃门）、方块搭桥 |

## 用好里程碑能力

- `maicraft:reach_milestone`（`milestone` = nether / stronghold / defeat_dragon / elytra）会根据现场事实推导前置并推进；`maicraft:defeat_ender_dragon`、`maicraft:obtain_elytra` 可在已到末地时单独使用。先读它们的完整契约再提交。
- 这些能力的关键许可都必须**显式**给出且有来源：`prepare_portal`（建/修传送门）、`allow_combat`（战斗）、`allow_rare_consumables`（消耗末影之眼或珍珠）、`may_alter_terrain`（改地形）。主播的目标里已经包含对应意图（例如“去打龙”即同意战斗）才设置；不确定就上报问一次，不要默认全开。
- 回执区分“看到了”和“做到了”：看到要塞不等于激活了传送门，攻击过龙不等于龙已死亡，鞘翅以真正进入主背包为准。

## 段间节奏

- 每完成一段用 `minecraft_report` 交付一次简短总结（拿到了什么、下一段打算），让主播有话可讲；不要攒到最后才说。
- 进入下界、末地这类危险段之前把据点、传送门位置用 `maicraft:remember_place` 记好。
- 死亡后先回据点补给，再判断是否继续当前段；装备掉在危险处时把“去不去捡”作为选项上报。

## 常见坑

- 末地里睡床会爆炸；把床当武器风险极高，没有把握不用。
- 末影之眼投掷有概率碎掉，按需要数量多备几颗。
- 下界里迷路是常态：从传送门出发就记地点，不要只凭感觉往回走。

## 何时上报

需要但没有拿到上述许可、或同一段连续两次死亡时，带上装备与卡点上报主播，请主播决定是加强准备还是换目标。
