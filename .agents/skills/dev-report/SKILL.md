# 开发周报长图

产出一张 **1080px 宽的竖版 PNG 长图**，读者是开发群与用户群里的两类人：懂开发的和只看直播的。一切内容以"不懂项目内部约定的读者第一眼能否看懂"为合格线。

## 输入

- **时间段**：参数缺省为本周一 00:00 到生成时刻；支持任意区间（"上周"、"11-01 到 11-08"、"最近 7 天"）。
- **下一步计划**：仅在用户主动给出时展示；用户没提就不放，不编造。

## 第一步：采集（git 是唯一事实源）

用 `git log --since/--until` 拉取区间内全部提交，统计：

- 提交总数；**首笔与末笔提交的实际时刻**（精确到分钟）——图上统计区间写这个，不写日历日期。
- 类型计数：feat / fix / test 计数，其余（docs、chore、refactor、style、merge 等）并入"文档与其他"；图例百分比必须合计 100。
- 每日提交计数（柱状图）。
- `--numstat` 增删行数、去重后的改动文件数。
- 区间内是否有 tag / 版本发布，有则在头部标注。

## 第二步：归纳改写（skill 的核心工序）

把 feat 按功能域聚类成组（组数随内容定，通常 4～6 组），fix **并入对应功能域组**，不单列"问题修复"节。硬约束逐条过：

- **只写 git 里有据的内容**，不虚构、不夸大；没把握的表述删掉，不靠修饰词撑。
- 用"**新特性**"，不用"新功能"（"功能"在读者眼里是大块能力）。
- **术语翻译成日常说法**：提交信息里的 scope、内部机制词不得照搬。对照表：代码与复盘文档里的"委派"在图中一律写"**委托任务**"；其余按"不懂内部约定的读者能否看懂"判定。
- **去"鱼八股"**（社区对 AI 套路文风的戏称）指纹，命中即重写：`不是……而是……`、`值得注意的是`、对仗排比句（"接得住、收得了场"式）、总分总模板腔、`整套机制`/`直接回应`/`赋能`/`落地`类正确的空话。改写方向：短句、具体事实、有具体对象，像人给群里捎话。
- 概述段常规字重，**最多加粗两处关键词**，不整段加粗。
- 修复条目保留"修复 X 因 Y 而 Z"的信息结构，但措辞日常化。
- 语言范本：CHANGELOG.md 的条目风格——写行为与结果，不写实现机制。

## 第三步：直播动态

数据源：`data/amaidesu.db` 的 `live_sessions` 表（场次号、起止时刻、时长）；剧情素材取 `.omo/livestream-analysis/` 下对应场次的复盘文档（场次概况节）。规则：

- 时长不足 5 分钟且无观众互动的场次按调试开场，不计入，在卡片后加一行小字说明（"另有 N 场 1 到 5 分钟的调试开场，未计入"）。
- 时长展示格式：**x小时y分**（如 2小时21分）；不足 1 小时写"y分钟"，全图格式统一。
- **10 场以内逐场一张卡片**；超过 10 场合并为一段总述加数字。卡片结构：
  - 场次号 + 日期 + 时长；
  - **剧情段**：这场直播发生了什么（取复盘文档，没有复盘文档就只写场次表能核实的事实）；
  - **"这场之后提交了什么"小节**：只看该场结束时刻之后、下一场开始之前的 git 提交，归纳成可读的几条。**问题与修复一律以提交信息为准**，复盘文档的结论仅作剧情叙述与理解辅助，二者冲突时信提交。
- 卡片区尾注一行："场次剧情取自复盘记录，修复内容以提交信息为准。"

## 第四步：填模板渲染

模板在 [assets/report-template.html](assets/report-template.html)，占位符以 `{{...}}` 标注并有注释说明；分组与场次卡片按内容增删。

渲染流程：

1. 起临时本地 HTTP 服务伺服模板文件（浏览器工具通常拦截 `file:` 协议），渲完即停。
2. 浏览器视口**先精确设为 1080 宽**再打开页面——浏览器重启后视口会回到默认宽度，截图前必须重新设置，否则产出两侧带灰边。
3. fullPage 整页截图出 PNG，交付前核验实际像素宽为 1080。
4. 浏览器报"配置目录已在用"类错误：清掉残留的自动化浏览器进程与配置目录锁文件后重试，属常见残留，不换方案。

## 第五步：视觉验收（交付前逐项过）

- 文字无溢出/截断/重叠，无孤字行（末行只剩一两个字）。
- 数据自洽：各分类之和 = 总提交数；每日柱之和 = 总提交数；图例百分比合计 100；柱高与数值趋势一致。
- 直播时长格式统一；"上了什么/查出什么"类生硬分类标签不出现。
- 去 AI 味装饰扫描：无紫色系、无渐变、无等宽字体、无细分隔线、无字距拉开的眉标题、无 emoji。
- 有问题改模板或文案后重截，通过后交付图片路径与内容摘要，等用户过目后再转发。
