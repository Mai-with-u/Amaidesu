# 复盘客观性自查清单（交付前硬门）

> 运行时点与产出要求：
> - **第六步交付前**：对整份复盘逐项过一遍（每个问题条目、每段结论、每个数字）。
> - **用户指正后**：重跑一遍，并定位漏检项属于哪一条——漏检项是对清单本身的修订输入。
> - **产出必须是"查出的问题"**：在复盘文档"复盘自查"节写明哪几项查出了什么、改了什么。只写"已过清单"不构成自查——清单的价值在于产出发现，不在于打勾。
> - 编号含义：A 断言 / B 证据链 / C 统计方法 / D 立场 / E 交付卫生。查法 = 怎么验证，不是怎么理解。

## A. 断言检查（每条"属实/一致/未复发"过一遍）

- **A1 口径归属**：每条"属实"标注了事实源是谁吗（世界记录 / 主播自述 / 主播状态块）？没有标注口径的"属实"退回重写。背包级字面属实不能放行世界级断言。
- **A2 正面结论配反证**：每条健康面/好样本/"未复发"，写过它的反证检查吗（查了什么、未发现/发现了什么）？好样本的**结尾**尤其要查——"结构完整"的收束可能正是事故的可见症状。
- **A3 全量还是抽样**：每个"N/N 全成 / 0 次 / 均 < X"标注了口径吗（全量核到每条 status / 抽样-下限估计）？抽样的不写成断言。
- **A4 数字来源**：每个计数注明文件范围（几个文件、什么时间窗）？单文件计数不写成"全场"。
- **A5 物体同一性**：每个"就是那张床 / 就是那个实体"有位置/时间/ID 佐证吗？叙事需要不构成证据。
- **A6 效果判语**：通篇搜"好看 / 节奏 / 完整 / 成功收束 / 有节目效果"——本场有观众反馈数据支撑吗？没有就删，降为"结构存在，效果未验证"。
- **A8 禁"未查"表述**：全文搜"待查 / 未核 / 未深入 / 暂不定案 / 建议复核"——每个命中三选一：当场查掉（首选，知道没查就现在查）；数据不存在则移入"问用户"清单；已调查至数据边界的改写为"已查到 X、边界在 Y"。报告正文零命中才算过。
- **A7 两可解读**：每个证据两可的点写的是不定式（可能 A 也可能 B），还是择优结论？择优的改回不定式。

## B. 证据链检查（每个问题条目过一遍）

- **B1 三级齐了吗**："没理会某信息"类定级，注入层（请求全文）和感知层（观察载荷）都下钻了吗？只停在行为层的不定级。
- **B2 静默事件的验证方式**："没发生 / 未触发 / 无响应"类结论是逐轮 diff / 逐条配对验证的，还是"没搜到就算没发生"？感知只报在场不报离场——离场必须 diff 出来。
- **B3 基础设施到句级了吗**：告警计数层结论升格成"健康/有问题"了吗？必须到"哪一句/哪一帧"。
- **B4 归属有证据吗**：本仓库 / Mod / 外部的归属给了传输层证据吗？注明对端版本或时点了吗？
- **B5 机制性延迟剔除了吗**：天色/天气类"说晚"有没有被误写成"与事实偏离"？决策时延量级入档了吗？
- **B6 与既往记录同构吗**：按形态关键词检索过复盘分析目录吗？命中的继承结论链，未命中的才新挖。

## C. 统计方法检查（每个数字的来源过一遍）

- **C1 方法先校准**：自写抽取/统计脚本拿已知正负样本试过吗（正例能检出、负例不误报）？
- **C2 首匹配落点**：文本抽取的第一个匹配落在哪个区块确认过吗（历史清单 / 实时状态 / 对话历史长得一样）？
- **C3 跨文件合并**：按小时轮转的日志合并后再计数了吗？
- **C4 可疑即疑脚本**：两场数字完全相同、计数与原始文件对不上——先疑脚本再疑数据，做了吗？
- **C5 截断输出补查**：`head` 截断的聚类输出，总数另行核过吗？

## D. 立场检查（对整份文档过一遍）

- **D1 影 vs 调查**：通篇有没有"这场的亮点是……"式叙事段落？复盘是事故调查不是影评——有就改写为结构陈述。
- **D2 裁定适用边界**：引用的用户既往裁定核了适用边界吗（矫枉场景的裁定 ≠ 通用法则）？裁定的前提条件单独核了吗？
- **D3 判据外主动跑**：用户点名之外，现成可机核的维度（情绪分布 / 指导语回放 / 决策时延 / 贴线轮次）主动跑完了吗？只审被点名的等于等指令。
- **D4 重犯对照**：上一份复盘自查节里的偏差类型，本份逐类对照过吗？
- **D5 我有没有想维护的叙事**：这份复盘里有没有一条结论，是"删掉它故事就不通了"的？有就对它做最严格的反证检查。

## E. 交付卫生

- **E1 文档结构**：时间线章节（矛盾逐条）/ 内容审计节 / 自查节 / 待拍板区四件齐吗？
- **E2 悬置项不蒸发**：上场待拍板与移交清单的现状逐条核对了吗？悬置的带原日期重列了吗？
- **E3 内部一致性 + 双载体同跑**：同一事实在时间线、问题条目、验收表三处的表述冲突吗（如"recap 正确"vs"recap 含一处失实"）？全文搜索关键词交叉核对。**markdown 与 HTML 两份载体各自独立过本清单**——"修完 md 后照着改 HTML"不算核对，两个载体会落后不同代（实测：HTML 曾落后三代：旧数字 4 处 + 已撤结论 1 处）。
- **E4 记忆同步**：主题记忆更新后，索引行刷新了吗？索引才是下次会话加载的那一层。

## 使用纪律

- 本清单本身也会漏：用户指正的新偏差类型，下一轮修订时按"三问"（去本场事实 / 非换皮 / 可执行）收进对应组；清单膨胀到失去逐条执行的可能时，按根源重组而不是加长。
- 自查结果写进复盘文档"复盘自查"节：**列出实际查出的项与改动**，不写"已逐项自查通过"。
